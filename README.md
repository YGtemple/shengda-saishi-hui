# 郑州升达经贸管理学院 · 赛事汇总站

面向全校学生的比赛 / 考试信息聚合页，纯静态单文件，无后端依赖。

## 内容

- 114 条赛事与考试信息（100 项竞赛 + 5 项公共考试 + 9 项校级赛事）
- 按学院分区：会计学院 21、公共比赛 18、信息工程学院 13、外国语学院 13、创新创业教育学院 10、建筑工程学院 9、体育学院 6、公共考试 5、机电学院 5、文法学院 5、艺术学院 5、数学与信息科学学院 4
- 级别口径依据《郑州升达经贸管理学院学生参加校外学科、技能竞赛获奖奖励办法》（达院字〔2017〕111 号）第五条

## 级别口径

| 级别 | 定义 | 数量 |
| --- | --- | --- |
| 国家级 | 教育部等国家行政部门、国家一级行业学会、教指委主办 | 70 |
| 省级 | 省教育厅等省级行政管理部门主办 | 20 |
| 校内 | 本校主办 / 院级（不适用校外竞赛奖励办法） | 15 |
| 行业级 | 企业、商业机构主办 | 6 |
| 待核实 | 主办单位本身不明 | 3 |

## 设计说明

- 不含倒计时：静态站点无法感知赛事延期，倒计时会误导。
- 不标注具体日期，只给报名入口与官方链接。
- 不承诺双创分，仅说明赛事本身价值。
- 晋级路径仅标注有官方证据的 5 项，其余不推测。

## 文件

- `index.html` —— 站点本体，单文件，可直接用记事本改
- `分类核对表.tsv` —— 114 条逐条核对表，含主办单位、官方链接、收录依据、级别判定依据
