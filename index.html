使用说明

关于这个网站怎么用、数据从哪来、要改怎么改。

1这些比赛从哪来

全部来自《郑州升达经贸管理学院 100 项竞赛官方文件汇编》，逐项取自主办方官网或官方主办单位页面，下载日期 2026-10-10。

本站只收录校级以上、有官方文件可查证的赛事，并标注赛事级别（国家级 / 省级）与主办单位，方便你判断含金量。

2为什么没有写截止时间

每届赛事的报名时间由主办方当年通知决定，常会调整、延期或改期。写死日期容易让你按过期时间去报名。

所以本站只给官方通知入口：点开比赛详情里的「打开官方通知」，看到的永远是最新、最准的一手信息。

3国家级 / 省级 怎么分

按主办单位层级划分，不是按比赛难度：

  • 国家级：教育部、工信部、共青团中央、全国学联、中国科协等部委，或全国性学会、行业协会主办。
  • 省级：河南省教育厅、省体育局、省人社厅等省级厅局主办。

同一个比赛可能既有国赛也有省赛，本站按索引收录的那一项标注。

4怎么更新比赛（维护者看）

用记事本打开 index.html，找到底部 var COMPETITIONS = [ ... ]，照着已有条目增删：

{ name, short, category, organizer, level, orgTier, url, src }

  • category 填学院规范全称（如「会计学院」），或「公共比赛」。
  • level 只能填「国家级」或「省级」。
  • url 必须是主办方官方域名，不要填培训机构或中介页面。
  • 列表按书写顺序显示，想调顺序就整条剪切移动。

5接入企业微信（维护者看）

  • 把 index.html 交给信息中心，由学校服务器托管并配置域名。
  • 以学校名义完成 ICP 备案，通过后把备案号填到文件底部 var ICP_NO。
  • 企业微信管理后台建自建应用，主页网址填站点地址。
  • 可见范围按「项目组 → 试点学院 → 全校」逐步放开。
  • 建好收集表后，把两个链接填到 FORM_URL 与 SHEET_URL。

6发现问题怎么反馈

  • 比赛信息有误、想补充比赛：联系所在学院联络员或项目组。
  • 页面打不开、样式异常：联系项目组技术维护。
  • 遇到可疑组队信息：先停止联系，再报项目组或学校保卫处。
